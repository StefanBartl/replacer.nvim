`:help replacer` carries the same reference in-editor, in
[`doc/replacer.txt`](../doc/replacer.txt).

`install.json` next to these files is not documentation — it is the machine-
readable tool declaration `lib.nvim.deps` reads; see
[installation.md](installation.md#declared-cli-tools). `Materials/` holds the
screen recordings [progress-indicator.md](progress-indicator.md) embeds. A
`map/` directory may also appear here: it is generated by `:DocMap`,
gitignored, and nothing links to it.
